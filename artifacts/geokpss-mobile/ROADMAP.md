# GeoKPSS Roadmap

## Phase 1 — Learning loop (current)
- [x] Keep study progress, notes, and quiz results on the device.
- [x] Show immediate correct/incorrect feedback on the silent map.
- [x] Add map quizzes for provinces, mountains, lakes, and rivers.
- [x] Schedule answered map items for spaced review and surface due items by topic.
- [x] Let learners create a personal note directly from a map feature.
- [ ] Add more verified questions and explanations for each supported layer.

## Phase 2 — Broader practice
- Extend map quizzes to plains, coasts, geology, soils, minerals, and projects.
- Add question formats for formation types, province-feature matching, and cause-and-effect.
- Add content references and a review process for exam facts and location data.
- Add topic filters and a clear per-topic mastery summary.

## Phase 3 — Study continuity
- Make the local study database resilient to export, restore, and device changes.
- Improve offline first-run behavior and make map/content availability explicit.
- Add optional study reminders only after the in-app review flow is stable.

## Phase 4 — Pro options
- Evaluate advanced reports, custom question sets, and expanded study packs.
- Keep core map exploration, topic tracking, notes, and a useful quiz path available.
- Do not lock or charge for features until the user explicitly chooses a monetization plan.

## Current review behavior
- A newly answered item is due again after one day.
- Correct consecutive reviews expand the interval to 3, 7, 14, and then 30 days.
- An incorrect answer resets the interval to one day.
- Due reviews appear in Konu Takibi and remain available until the learner completes that review question.
